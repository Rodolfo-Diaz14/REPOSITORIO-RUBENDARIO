
# Rubén Darío — Portal (GitHub Pages)

Estructura de sitio web tipo portal con **imágenes integradas** en la página de inicio y en secciones.

**Publicación:**
1. Suba todo el contenido de esta carpeta al root de su repositorio.
2. Settings → Pages → Build and Deployment: **Deploy from a branch** → `main` → `/ (root)`.
3. Guardar y esperar 1–2 minutos.
